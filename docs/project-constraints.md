# DshForMac 项目约束

通用产品与技术约束见 [AGENTS.md](../AGENTS.md)，具体流程见 [架构设计](architecture.md)。

## 子进程环境

- 子进程 PATH 优先使用选定 Node 与检测到的 pnpm 目录，保留继承路径，读取 `/etc/paths` 和 `/etc/paths.d`，再补齐两种 Mac 架构的 Homebrew 与系统目录，支持 DSH 内交互式 shell 查找配置依赖。仅影响子进程，不修改全局 PATH 或用户 shell 配置。
- 内嵌终端可使用本机已安装的 Nerd Font 补充私用区图标；兼容样式仅作用于终端，不自动安装字体、不修改 DSH 包。

## DSH 更新

- 设置中的“DSH 检查标签”支持多选，首项 `latest` 默认勾选且不可取消；检查标签与包下载镜像修改后立即保存，后续检查和下载直接使用新设置，无需先点击“保存”。
- 检查频率支持每次启动、每天、每周、每月和不检查。周期检查必须覆盖应用持续运行、重新激活与系统唤醒的情况；每次启动不能变成周期轮询请求。
- 检查只读取候选版本与本地安装状态，发现更新立即显示“有新版本”。不得因发现更新而自动下载安装。
- 设置界面的状态说明询问是否下载，并提供链接样式的“下载”按钮，不使用弹窗。用户点击后下载所提示的精确版本，失败后可手动重试。
- 待下载状态跨应用重启保留。首次启动所需运行时的安装与用户主动重新下载流程继续使用现有启动行为。
- 下载校验与启动健康检查分开；下载完成不得替换正在运行的服务或更新 `runtimes/current`。
- 启动健康检查通过后，默认保留最新 5 个受管版本，稳定版与预发布版合并计数；当前运行或用户固定的版本不在其中时额外保留，不能自动删除。
